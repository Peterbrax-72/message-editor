# Message Editor

A simple message editor with Inbox, Outbox, and Drafts.

## Run locally
Open `index.html` in a browser.

## Build APK on GitHub
1. Push this repository to GitHub.
2. Go to the **Actions** tab.
3. Wait for **Build Android APK** to finish.
4. Download the **MessageEditor-APK** artifact.
5. Install the `.apk` on an Android device.
"# message-editor"
